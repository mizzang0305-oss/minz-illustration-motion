# 연출과 검수

## 원화 준비

- 원본 해상도와 안전하게 잘라낼 수 있는 범위를 먼저 확인한다. 원화 한 장과 같은 좌표계의 알파 PNG 레이어를 사용하고, 파생 파일은 별도 저장한다. 배경 여백은 같은 이미지에서 확보하고, 발밑·몸 뒤처럼 새로 노출되는 영역은 사용자가 제공한 클린 플레이트 또는 같은 그림 내 정합성 있는 부분으로만 보완한다. 배경이 갖춰지기 전에는 카메라 이동을 줄인다.
- 초깃값부터 가장 크게 흔들리거나 회전하는 프레임까지 역변환한 화면 네 귀퉁이가 배경 안에 들어가는지 확인한다. 인물·소품은 화면 경계와 의도한 앵커를 각각 확인한다. 중요한 선과 실루엣에서 투명 프린지나 색 번짐을 점검한다.
- 장면별 설정에 원본 경로 `image`, 기법 ID `effect`, 시간 `frames`, 강도 `intensity`를 둔다. 복수 효과는 주 기법을 ID로 넣고 보조 효과와 앵커를 `params`에 기록한다. 장면에 효과가 없으면 `none`을 사용한다. `layers`는 역할별 파생 파일 경로를 가진 객체로 관리한다. 위치 앵커는 원본 기준 0–1 좌표를 쓴다.

## 기법 구현

Remotion에서 장면을 Sequence로 묶고 장면 상대 프레임으로 움직임을 계산한다. 값은 프레임에서 재현 가능하도록 계산하고, 파티클과 흔들림은 시드를 고정한다. 인물과 배경에 공유할 카메라 변환과 레이어별 변환을 구분한다. 아래 수치는 시작값이며 실제 화면과 원화 여백에서 강도를 조정한다.

| ID | 기법 | 움직임과 검수 |
| --- | --- | --- |
| `punch-shake` | 줌 펀치 + 흔들림 | 반응 프레임에서 얼굴 또는 몸 쪽으로 4–5프레임(약 0.15초)에 당긴다. 5–10% 확대에서 시작하고 X/Y 진폭을 빠르게 줄여 안정시킨다. 처음과 끝에서 얼굴이 프레임 안에 있는지 본다. |
| `parallax` | 2.5D 패럴랙스 | 인물·근경 지면·중경 숲·원경 산을 분리한다. 지면·인물·숲·산 이동 배율의 시작값은 1.0·0.75·0.35·0.08이다. 인물과 지면의 접지, 가려졌던 배경의 노출을 확인한다. |
| `orbit` | 3D 카메라 궤도 | 피사체 중심을 고정하고 ±2–4°의 작은 카메라 궤도에서 시작한다. 깊이에 놓인 배경 평면에는 원근 변화를 주고 인물은 카메라를 향한 평면으로 유지한다. 얼굴 자체의 메시나 perspective warp를 사용하지 않는다. |
| `dolly-zoom` | 돌리 줌 | 카메라에서 인물까지의 거리 D(t)와 초점 거리 f(t)를 f(t)/D(t)가 일정하도록 묶는다. 배경은 별도 깊이에서 투영하며 인물 얼굴 앵커와 화면상 크기를 유지한다. 시작·최대·끝에서 얼굴 크기 편차 2% 이내를 우선 목표로 한다. |
| `puppet` | 캐릭터 퍼펫 | 몸통의 미세한 호흡, 고개 회전, 어깨·옷자락을 분리한다. 고개는 목을 축으로 1–2° 내에서 강체 회전하고 손과 얼굴은 원본 픽셀을 유지한다. 어깨와 옷자락은 2–4프레임 늦추고 이음부를 원화 실루엣 안에 둔다. |
| `entrance` | 등장 연출 | 오른쪽 화면 밖에서 시작해 사용자 지정 위치에 감속해 도착시킨다. 평면 이동과 작은 상하 들썩임을 발 디딤 프레임에 맞추고 같은 위치에 짧게 사라지는 흙먼지를 합성한다. 바닥선과 발 미끄러짐을 확인한다. |
| `rack-focus` | 랙 포커스 | 시작은 뒤쪽 길 선명·앞 인물 흐림, 끝은 그 반대로 전환한다. 두 레이어의 흐림을 약 12–24프레임 동안 교차 보간한다. 마스크 확장과 premultiplied alpha 처리를 확인해 밝은 테두리를 줄인다. |
| `lamp-light` | 빛 연출 | 방은 어둡게 유지하고 등잔 주변에 따뜻한 마스크를 둔다. 일정하지 않은 완만한 밝기 변화에 얼굴·벽의 지역 마스크 밝기를 같은 위상으로 약하게 동기화한다. 피부색과 선을 보존하고 밝은 부분이 날아가지 않게 한다. |
| `weather` | 날씨 레이어 | 멀리 작고 느린 눈, 눈앞에 크고 빠른 눈을 별도 깊이에 둔다. 낮은 안개는 지면을 따라 옆으로 움직인다. 눈과 안개가 얼굴과 중심 동작을 계속 가리지 않도록 한다. |
| `whip-pan` | 휩 팬 전환 | 나가는 컷 마지막과 다음 컷 첫 프레임을 하나의 동작으로 설계한다. 화면상의 이동 방향·피크 속도·방향성 블러를 맞추고, 경계 양쪽에서 짧게 적용한 뒤 다음 컷을 안정시킨다. 필요하면 같은 이동 축의 과스캔과 프레임별 이동 누적 샘플로 블러를 만든다. |
| `ken-burns` | 켄 번즈 | 장면 전체에 걸쳐 시선 앵커로 천천히 이동하며 4–8% 확대에서 시작한다. 석양의 고갯마루처럼 여운을 주는 장면에 사용하고 수평선과 중심 피사체가 의도한 구도에 남는지 본다. |

## 최종 출력

- 49초 시연 프리셋의 길이는 참고 영상의 편집 인상을 재현할 시작값이다. 원본 그림 경로를 교체한다. 기능을 설명하는 자막은 상단 기법명과 하단 한 줄을 UI 안전 영역에 두고, 9:16 모바일 미리보기에서 잘림과 대비를 확인한다. 휩 팬 모션 블러는 자막에 적용하지 않는다. 이야기 모드에서 사용자가 요청한 대사 자막은 기법 설명과 별개로 취급한다.
- 새 구현에서 Remotion으로 정확한 크기·프레임레이트의 중간본을 렌더한 뒤 다음처럼 인코딩한다. 중간본에 소리가 있으면 유지하고, 소리가 없으면 무음 영상으로 출력한다.

```sh
ffmpeg -n -i intermediate.mp4 -map 0:v:0 -map '0:a:0?' -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart final.mp4
```

- 렌더된 장면별 실제 효과와 강도, 줄이거나 바꾼 이유를 계획의 `applied`에 기록한다. 자동 검사는 MP4 컨테이너, 코덱·크기·프레임레이트·픽셀 포맷·실제 프레임 수를 확인한다. 시각 품질은 최종본을 재생해 확인한다.
